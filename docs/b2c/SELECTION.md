# B2C選定プロセス全記録 — 日本toC個人開発アプリ

**日付**: 2026-07-02
**手法**: multi-agent敵対的選抜パイプライン(選抜工程: 26エージェント / 約188万トークン / 626ツール実行、Web一次情報照合を含む)
**前回との関係**: 同リポジトリのToriiGate選抜(B2B・グローバル収益前提、[`../SELECTION.md`](../SELECTION.md))とは独立の新規選抜。今回の前提は**日本国内・コンシューマー向け・ソロ個人開発**。

## 1. パイプライン設計

```
Research(7本の並列市場調査 — 市場経済/個人開発実例/課金メカニクス/人口動態ペイン/AI事情/競合密度/流通)
  → Ideate(5レンズ × 3構想 = 15構想、各構想に提案前の実競合検索を義務付け)
  → Consolidate(意味的重複の統合 — 15→12構想)
  → Judge(4人の敵対的審査員 × 12構想、加重: 収益性0.35 / ソロ実現性0.20 / 競合・流通0.25 / 日本市場適合0.20)
  → Verify(上位3構想 × 3スケプティック(需要/競合/実行・法規制)の実地デューデリジェンス)
```

**前提条件(全構想に共通で課した制約)**:
- 開発者は日本在住のソロ(1人)エンジニア。外部資金なし。デザイン・マーケも1人
- 対象は日本のコンシューマー(toC)。B2Bは対象外
- リリース後3〜6ヶ月で最初の収益、12ヶ月で月10〜30万円、24ヶ月で月50〜100万円が現実的に狙えること
- 継続的な人的オペレーション(在庫・配送・人手サポートの大量発生)を必要としないこと
- 法規制(薬機法・資金決済法・出会い系規制・景表法・著作権)抵触時は回避策を明記
- AI利用は任意 — 「AIだから」ではなく「儲かるから」で選ぶ
- 巨大プレイヤー(LINE・リクルート・サイバーエージェント等)が半年で潰せる位置は避ける

**アイデア生成の5レンズ**: 生活ペイン起点(pain-first)/ 財布起点(wallet-first)/ AI-native起点 / 高WTP趣味ニッチ起点(otaku-niche)/ 地味ユーティリティ起点(boring-utility)

**審査員設計**: 各審査員は「まず構想を殺しにかかれ、steelmanは攻撃の後」と指示。fatal_flaw(そのままでは事業がほぼ確実に失敗する欠陥)を2件以上宣告された構想は自動棄却。

市場調査の全文は [`RESEARCH.md`](RESEARCH.md) を参照。

## 4. 判断根拠 — なぜドウジン決算か

conviction調整幅(-22 vs -37 vs -44)の差は、**前提が検証に耐えた度合い**の差である:

1. **中核主張の生存**: ドウジン決算の中核主張(委託精算書の横断取込〜棚卸〜帳票の通貫ツール不在)は、殺す前提で放った14クエリの検証でも崩れなかった。チョウラクは中核のwhy-now(日本語化前の時間窓)がDDで既に閉じていたことが判明し、バンソウは「専用アプリの空白」が機能レベルで既に埋まっていた(GakuMate)。

2. **法規制リスクの質**: ドウジン決算の法的立て付けは国税庁の一次情報で「白」を確認できた(申告書作成ソフトの開発・販売は税理士業務に非該当 — freeeと同じ防衛線)。チョウラクは薬機法グレー+要配慮個人情報+ストアの法人アカウント要件の三重苦、バンソウは自炊代行・MYUTA判例という司法判断済みの地雷の上に中核機能が乗る。**「グレーを運用で回避する」構想より「白を維持する」構想が、ソロには安全域が桁違いに広い。**

3. **競合の構造**: ドウジン決算のニッチ(申告対象5〜15万人)はfreee/弥生には小さすぎ、ドージン・ドット・タックス(年16万円〜)とは価格帯が40倍違い、無料テンプレとは「委託複数社の突合・棚卸自動化」で機能が違う。バーベルの中間は薄いが、**その薄さこそが大手不在の理由**であり、月10〜30万円というソロの目標には十分な池である。チョウラクはMonash+国内2社の同盟、バンソウはGakuMate・宿題スキャナー・塾公式デジタル化と、いずれも埋まりつつある空白だった。

4. **失敗時の損失**: ドウジン決算は精算書パーサ+会計ロジックという資産が隣接クリエイター市場(Vtuber・ハンドメイド・ネットショップの兼業層)へ転用可能。健康データも子どもデータも扱わないため、撤退時の後始末も軽い。

5. **タイミングの一致**: 2026年7月着手→11月β→2027年2-3月申告期という自然なカレンダーが存在する。収益の季節偏在は弱点だが、**申告は毎年必ず来る**という構造的リピートでもある。

## 5. この選定の限界(明示)

- 調査はWeb公開情報+モデル知識に基づく。**同人作家への顧客インタビュー0件** — 実装計画の事前検証工程(LP+事前登録実験)が最初の実地検証となる。
- 「委託複数社ユーザー」セグメントの実サイズは未検証。コミケ3.5万サークル/回・申告対象推定5〜15万人はいずれも推計であり、ドージン・ドット・タックスが10年で契約1,000件という実測値は、課金母集団が推計より小さい可能性を示唆する(実装計画のkill criteriaで規律)。
- 収益予測は全て仮説。DDによる下方修正済み(転換率2〜5%、初年度は当初計画の1/3〜1/2)の数字を基準とした。
- App Store/Google Playのストアページ直接取得が一部プロキシ制限で不可だったため、競合アプリの評価件数・最終更新日の一部は二次情報(比較記事)に依拠している。
