## ドウジン決算(B2C・日本toC) — 2026-07-02選定

> 同人作家専用の確定申告「前処理レイヤー」Webアプリ。とらのあな・メロンブックス・BOOTHの精算書を放り込むと、突合・棚卸まで済んだ年間収支が確定し、国税庁作成コーナー/freee/弥生にそのまま持っていける。

### 結論(TL;DR)

| 項目 | 内容 |
|------|------|
| **顧客** | 委託複数社(とら/メロン+BOOTH)併用の兼業同人作家。申告対象人口は推定5〜15万人 |
| **価格** | 申告年度パス(買い切り)¥2,480 / 早割¥1,980 / 2年パック¥3,980。サブスクなし |
| **初年度目標** | 中央シナリオ: 有料160件・売上約35万円(2027/3末)。初年度は損益トントンで「実データ検証と資産蓄積」、勝負は2年目の更新+隣接拡張(Vtuber/配信者等) |
| **なぜ勝てるか** | 委託精算書の横断取込→突合→棚卸の通貫ツールは無料代替が存在しない(敵対的DDで14クエリ検証済み)。freee/弥生にはニッチすぎ、税理士系(年16万円〜)とは価格帯が10倍違う中間の空白 |
| **法的立て付け** | 「申告書作成ソフトの開発・販売は税理士業務に非該当」を国税庁一次情報で確認済み。税務判断ゼロ回答の二値サポート・マイナンバー非取扱い・電帳法非訴求で構造的にリスク遮断 |
| **最初のゲート** | 2026年7月中の需要検証(予算3万円: LP事前登録+500円先行予約+BOOTHテンプレ販売実験)→ 8月第1週GO/NO-GO判定。**コードはその後** |

### 選定プロセス

単一の思いつきではなく、multi-agentの敵対的選抜パイプラインの生存者である:

1. **Research** — 日本市場の並列調査7本(市場経済構造/個人開発の収益化実例/課金メカニクスとスマホ新法/人口動態ペイン/AIコンシューマー事情/競合密度/流通・ASO)。日本語一次情報をWeb検証付きで収集
2. **Ideate** — 5レンズ(生活ペイン/財布/AI-native/趣味ニッチ/地味ユーティリティ)× 3構想 = 15構想。各構想に提案前の実競合検索を義務付け
3. **Judge** — 4人の敵対的審査員(収益性/ソロ実現性/競合・流通/日本市場適合)× 12構想(統合後)
4. **Verify** — 上位3構想 × 3スケプティック(需要/競合/実行・法規制)の実地デューデリジェンス
5. **Design** — 勝者に対し7領域の並列設計(製品/会計エンジン/技術/価格/GTM/法務/事前検死)+ 整合性クリティークで15件の矛盾を解決

計34エージェント、約276万トークン、約700回のツール実行(Web検索・一次情報照合を含む)。

### 正直な評価

- 上位3構想はいずれもkill票0だったが、DD後のconviction調整はドウジン決算-22、チョウラク-37、バンソウ-44。**勝因は「中核主張が検証に耐えた度合い」と「法規制リスクの質**(グレーの回避運用ではなく白の維持)」
- 需要はバーベル型(高額丸投げ層と無料充足層)で中間が薄いことがDDで判明済み。当初の年3,980円サブスクは棄却し、シーズン買い切り¥1,980〜2,480に再設計。転換率2〜5%・初年度収益は当初計画の1/3〜1/2に下方修正済み
- 最大リスクは「委託複数社セグメントが支払う集団として小さすぎる」(事前確率30%)。だからコードを書く前に3万円で検証する
